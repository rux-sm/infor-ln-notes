Scenario Guide · v2.2

Manual Production Order from Existing Master Data

create a quantity-one manual production order from an existing finished item, existing components, an existing BOM, and an existing routing; verify the generated operations and estimated materials; release the order; issue material to the job shop; report the operation(s) complete; and confirm the finished item is received into the warehouse.

Completion BoundaryCompleted production order + finished item received into warehouse inventory
Run This Guide
  1. 0Confirm the existing foundation
  2. 1Create the production order
  3. 2Verify the generated foundation
  4. 3Release the order
  5. 4Issue material to the job shop
  6. 5Report the operation complete and confirm warehouse receipt

0 · Confirm the existing foundation

WarehousingInventory 360Inventory 360 whwmd4300m000

0.1Obtain one prequalified training case from the master-data owner✎ finished item and ✎ component item, with an existing valid BOM and routing
0.2Enter the component item in Filter Items and run itThe component appears with inventory totals
0.3Tick the component row and click Warehouse Inventory in the Inventory groupWarehouse - Item Inventory whwmd2515m000 opens for the component
0.4Select a warehouse row with enough unblocked stock for the quantity-one order✎ component warehouse and ✎ component on-hand before
0.5Confirm the training case identifies the receiving warehouse, valid BOM revision, valid routing revision, and expected operationAll inputs needed to check the created order are known before entry begins
0.6Repeat steps 0.2–0.3 for the finished item, filtered at the receiving warehouse the training case identifies✎ finished item on-hand before

1 · Create the production order

ManufacturingJob ShopProduction OrdersProduction Orders tisfc0501m000

1.1Click NewA new production-order record opens
1.2Enter the finished item from step 0.1The item is accepted for the order
1.3Confirm Site for the training case✎ site
1.4Enter 1 in Quantity Ordered✎ production quantity = 1
1.5Confirm Warehouse is the intended receiving warehouse✎ receiving warehouse
1.6Confirm Production Start, Planned Delivery Date, and Planning Method are suitable for the training runThe order dates remain within the qualified BOM and routing dates
1.7If the item is revision controlled, select the qualified item revision supplied with the training caseThe selected revision is visible before save
1.8Click SaveOrder Status = Created — ✎ production order number

2 · Verify the generated foundation

ManufacturingJob ShopProduction OrdersProduction Orders tisfc0501m000, then drill in to Production Order tisfc0101m100

2.1Double-click the production order recorded in step 1.8Production Order opens for the same order
2.2Compare the displayed BOM and revision with the qualified training case✎ BOM and revision match the expected foundation
2.3Compare the displayed routing and revision with the qualified training case✎ routing and revision match the expected foundation
2.4Open the production-planning area and confirm the expected operation is present✎ expected operation; Operations Present is selected in the overview
2.5Open the estimated-materials area and confirm the expected component and quantity✎ estimated component quantity for the component from step 0.1
2.6Return to the overview without running a release or processing actionThe order remains Created and no material issue has begun

3 · Release the order

ManufacturingJob ShopProduction OrdersProduction Orders tisfc0501m000, Actions ➔ Release Orders — Release Production Orders tisfc0204m000

3.1Select the production order row from step 1.8The row is highlighted
3.2Actions ➔ Release OrdersRelease Production Orders tisfc0204m000 opens
3.3Confirm the selection range narrows to this one production orderOnly this order is in scope for the release run
3.4Run the releaseThe dialog closes; back in Production Orders, ✎ order status after release = Released
3.5Confirm no other order changed statusOnly the order from step 1.8 shows Released

4 · Issue material to the job shop

4.1Open Material to Issue for Production Orders for the order released in phase 3The component line from step 0.1 is listed, with Production Order Status Released
4.2Read Estimated Quantity, Actual Quantity, and To Issue by Warehouse for the component line✎ material to issue = the To Issue by Warehouse figure; Actual Quantity = 0
4.3If the line is not already unblocked, run Initiate Inventory Issue tisfc0207m000 for the lineThe material's warehouse order line unblocks
4.4Open Warehousing Orders whinh2100m000 and find the production issue order for this production orderThe order shows order type 30- Production (Out), source the component warehouse from step 0.4, destination the work center from the routing
4.5Drill in to the issue order — Warehousing Order whinh2100m100The order lines and the Outbound Line Status Overview whinh2129m000 activity list are visible
4.6If Generate Outbound Advice and Release Outbound Advice show unfinished and not automatic, run themThe advice is generated and released
4.7Continue the outbound procedure until the issue order reaches ShippedOrdered and advised quantities match; the order shows Shipped
4.8Return to Material to Issue for Production Orders and Production OrdersActual Quantity = the estimated quantity, To Issue by Warehouse = 0; ✎ order status after material issue = Active

5 · Report the operation complete and confirm warehouse receipt

5.1Open Report Operations Completed for the order's next operationThe operation line shows Operation Status, Planned Output, and the item from step 0.1
5.2Enter the production quantity from step 1.4 in CompletedThe quantity is accepted
5.3SaveIf this was the last operation, LN can book the completed product into inventory
5.4Repeat steps 5.1–5.3 for each remaining operation, in routing sequenceEach operation reports complete in turn
5.5On the last operation's save, if Report Orders Completed tisfc0120s000 opens, confirm Quantity Delivered and save✎ quantity delivered = the production quantity
5.6Return to Production Orders tisfc0501m000Order Status = Completed; Quantity Delivered = the production quantity, Quantity to Deliver = 0
5.7Open Inventory 360 whwmd4300m000 and filter the finished item at the receiving warehouse from step 1.5✎ finished item on-hand after; on-hand has increased by the production quantity over step 0.6
